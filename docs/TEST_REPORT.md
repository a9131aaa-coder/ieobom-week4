# 5주차 검증 기록

검증일: 2026-10-17. 코드 버전 0.2.0.

## 확인한 항목

- Next.js 16.4.2 production build 성공. TypeScript 검사 통과.
- npm test 자동 테스트 13개 통과.
- API: MOCK 원본 유지, 커스텀 입력 검증, 실제 보유 ID만 허용, 3개 결과 형식 검증.
- 모의 공급자를 통한 성공 응답(fallback:false), 토큰·추론 원가 산식, 키가 응답/URL에 포함되지 않는지 확인.
- 키 누락, 의도적 실패, 인증 오류, 429, 없는 모델, 빈 응답, 불완전 응답, 깨진 JSON, 연결 오류, 시간 초과에서 대체 결과 확인.
- DOM 동작: 5개 메뉴 전환, 옷 등록·삭제, 프로필 저장, 코디 분석 결과 표시·저장, 중복 저장 방지, 기록 상세·평가, 저장 후 새 세션 복원.
- 사용자 입력의 HTML이 실행되지 않고 문자로 표시됨을 확인.
- 초기 대시보드 로드 오류와 재시도 복구 확인.
- 컴파일된 production 라우트 함수를 Request/Response로 직접 호출해 dashboard 200, 대체 응답 200, 입력 400, 본문 크기 413, 외부 Origin 403, Content-Type 415 확인.
- 비밀 키가 포함되지 않은 배포 ZIP, 빈 .env.example, .gitignore 확인.

## 남은 확인

- 본인의 실제 Gemini 키로 공급자 호출. 자동 테스트의 성공 응답은 모의 응답이며 실제 AI 성공 증거가 아닙니다.
- 실제 Vercel 배포와 Network 200/fallback:false 캡처.
- 실제 휴대폰에서 레이아웃·메뉴·AI 결과 확인. 반응형 CSS와 viewport는 구현했으나 이번 환경에서는 실제 브라우저 화면과 휴대폰을 검사하지 않았습니다.
- 로컬 HTTP 서버 종단 테스트는 이 실행 환경에서 완료되지 않았습니다. 서버 함수 직접 호출 결과와 실제 배포 HTTP 결과를 구분합니다.
- 실제 토큰 원가 기록과 게이트③ 비교, 본인 경험의 한 줄 회고.

개발 환경 Node.js 24.19.0에서 검증했습니다. 프로젝트의 Vercel 실행 설정은 기존 Node.js 22.x를 유지합니다. Next.js 및 사용 API는 해당 버전을 지원하지만 실제 Vercel 빌드 로그를 확인해야 합니다.
