[공개 배포 확인 후 사용할 짧은 설명]

입어봄은 내 옷과 취향을 기억하는 AI 코디 컨설턴트입니다.
이번 4주차에는 홈 대시보드 한 화면을 구현했습니다.
남은 상담 횟수, 등록한 옷, 취향 프로필 카드 세 개와 최근 코디 상담 다섯 건을 보여줍니다.
모든 숫자와 기록은 화면에 직접 적지 않고 /api/dashboard에서 JSON으로 받아옵니다.
현재는 수업용 예시 데이터이며, AI 연결은 5주차에 진행할 계획입니다.

[제출 전 반드시 직접 확인]
1. Vercel 빌드 상태 Ready
2. 휴대폰 또는 시크릿 창에서 공개 주소 열기
3. F12 > Network > Fetch/XHR > 새로고침 > dashboard 상태 200 확인 후 캡처
4. 배포 주소 뒤 /PRD.html 열기
5. 본인이 실제로 겪은 어려움과 해결 방법 한 줄 작성

[아직 완료되지 않은 것]
배포 계정 연결, Vercel 빌드, 공개 주소 생성, 실제 Network 캡처는 사용자 환경에서 마무리해야 합니다.
